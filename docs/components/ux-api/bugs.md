# Bugs

Report bugs through GitHub Issues on the relevant repository — not through this documentation section.

## Where to file issues

| Area | Issues |
| --- | --- |
| CLI | [verilib-cli issues](https://github.com/Beneficial-AI-Foundation/verilib-cli/issues) |
| Frontend | [verilib-frontend issues](https://github.com/Beneficial-AI-Foundation/verilib-frontend/issues) |
| Atomizer | [verilib-atomizer issues](https://github.com/Beneficial-AI-Foundation/verilib-atomizer/issues) |
| Certificates | [local_validate issues](https://github.com/Beneficial-AI-Foundation/local_validate/issues) |
| Documentation | [engineering-docs issues](https://github.com/Beneficial-AI-Foundation/engineering-docs/issues) |

## General guidance

Include reproduction steps, expected vs actual behavior, and versions (CLI version, browser, OS). For security issues, see [Security](../devops/security.md) and report through the appropriate private channel — do not open public issues for vulnerabilities.
